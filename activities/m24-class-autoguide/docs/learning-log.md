# Diario de aprendizaje

Este documento requiere respuestas personales del estudiante. No se completó automáticamente para evitar atribuirle aprendizaje o experiencia que no se haya expresado.

## Antes de estudiar

- ¿Qué entiendo por tenant y aislamiento?
- ¿Qué entiendo por transacción e idempotencia?
- ¿Qué parte del flujo vending me resulta menos clara?

## Durante el estudio

Para cada módulo de `../theory/`, anota:

- concepto explicado con mis propias palabras;
- duda que hice al tutor;
- respuesta que comprobé en el código o en una prueba;
- algo que todavía no puedo explicar.

## Después de implementar

- ¿Qué regla de negocio fue más difícil de preservar?
- ¿Qué prueba me convenció de que funciona?
- ¿Qué sugerencia de IA revisé, cambié o rechacé?
- ¿Qué cambiaría antes de conectar hardware o pagos reales?
