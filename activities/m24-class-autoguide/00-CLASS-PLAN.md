# Clase autónoma — Investigación y lanzamiento de M24

## Duración

3 horas, incluyendo 10 minutos de descanso.

## Resultado de la sesión

Cada estudiante termina con:

- reporte de aprendizaje generado por Gemini;
- registro personal de conceptos y dudas;
- especificaciones revisadas;
- plan de implementación;
- repositorio inicial;
- conexión a Supabase;
- modelo inicial de datos;
- primera vertical en progreso o ejecutable;
- commit de checkpoint.

## Cronograma

| Minutos | Actividad | Evidencia |
|---:|---|---|
| 0–10 | Abrir guía, preparar Gemini y leer reglas | Tutor iniciado |
| 10–60 | Módulos de aprendizaje guiado | Respuestas y checks |
| 60–70 | Síntesis y reporte de preparación | Reporte Gemini |
| 70–80 | Descanso | — |
| 80–95 | Leer alcance y flujo completo | Preguntas anotadas |
| 95–115 | Modelo, tenants, estados y permisos | Plan inicial |
| 115–135 | Crear repositorio y configurar apps | Proyecto ejecutable |
| 135–155 | Conectar Supabase y crear migraciones | Base inicial |
| 155–170 | Primera vertical | Endpoint o flujo |
| 170–180 | Evidencia, commit y checkpoint | Commit y reporte |

## Dinámica

- Trabajo estrictamente individual.
- El material debe poder seguirse sin exposición constante.
- El docente acompaña, desbloquea y formula preguntas.
- Gemini funciona primero como tutor y después puede funcionar como asistente de implementación.
- El estudiante conserva responsabilidad sobre contrato, decisiones y verificación.
- Si el asistente abandona el modo acordado, el estudiante utiliza `prompts/03-BEHAVIOR-RECOVERY.md` antes de pedir ayuda docente.

## Intervenciones docentes recomendadas

- “¿Qué sabes y qué estás suponiendo?”
- “¿Cuál es la frontera del tenant?”
- “¿De dónde proviene esa identidad?”
- “¿Qué estado puede quedar inconsistente?”
- “¿Qué prueba demuestra esa regla?”
- “¿Qué ocurre si la petición se repite?”
- “¿Qué pasa si dos usuarios compran la última unidad?”
- “¿Qué parte produjo la IA y cómo la verificaste?”

## Cierre de la sesión

Cada estudiante debe mostrar:

1. repositorio;
2. aplicaciones que arrancan;
3. conexión a Supabase;
4. migraciones creadas o ejecutadas;
5. plan de implementación;
6. primera vertical;
7. siguiente tarea concreta;
8. duda técnica principal.
