Fase 2

Convierte conocimiento en decisiones

Ahora sí puedes utilizar IA para planificar y programar. Primero resume el cambio, identifica invariantes y define cómo lo verificarás.

1. Comprende

  • Lee alcance y arquitectura.

2. Diseña

  • Modelo de datos.

  • Permisos.
  • Primera vertical.

3. Construye

  • Tres apps.
  • PostgreSQL/Supabase.
  • Migraciones y seed.
  • Contrato mínimo.

4. Verifica

  • Ejecuta.
  • Prueba.
  • Guarda evidencia.
  • Explica límites.
Puedes cambiar la estructura recomendada, pero debes justificar cómo preserva tenant isolation, responsabilidades y verificabilidad.
Entrega semanal

Cuatro piezas, un solo sistema

La plataforma debe demostrar un recorrido integrado, no cuatro proyectos aislados.

APP 1

Admin web

Tenants, acceso, ubicaciones, máquinas, catálogo, inventario, órdenes, pagos, despacho, reportes y auditoría.

APP 2

Vending web

Simulador desktop, QR y experiencia móvil del comprador.

APP 3

Backend

REST, RBAC, tenant context, estados, consistencia, idempotencia, logs y pruebas.

DATA

PostgreSQL / Supabase

Migraciones, seed, constraints, índices, transacciones, reservas, ledger, auditoría y aislamiento.

Flujo obligatorio

Configurar→Mostrar QR→Comprar→Pagar→Despachar→Actualizar stock→Reportar
